# Stream Deck profile

The exported Rally Academy profile for the Elgato Stream Deck Mk.2 goes here
(`Rally Academy.streamDeckProfile`). Double-click it to import.

Layout, default keys (F13–F24) and how to build or export the profile:
[docs/STREAM_DECK.md](../../docs/STREAM_DECK.md). This folder is not part of the mod zip.
